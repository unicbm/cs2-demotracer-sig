# Scope

Keep this repository public and independent of private desktop source. Read product compatibility data from immutable commits in unicbm/demotracer. Do not maintain copied signatures or automatically repair, patch, or deploy product configuration.

Reports must distinguish static byte matches, runtime initialization and replay validation. Never upgrade untested checks to pass. Bind evidence to the exact game and product build. Treat source format drift as an error.

Never commit game files, demos, replays, local paths, Steam account data, logs or credentials. Run `node --test` and inspect the staged report data before pushing. Preserve the GPL attribution of src/pe.mjs.
